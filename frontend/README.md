# Frontend

React + TypeScript (Vite), styled with Tailwind CSS and a few shadcn/ui components. It talks to the backend only through the REST and WebSocket contract in `../docs/API.md`.

## Run

```bash
npm install
npm run dev          # http://localhost:5173, forwards /api and /ws to the backend on 127.0.0.1:8080
npm run lint
npm run build
```

Open `http://localhost:5173/?mock` to see the page with sample data when the backend is not running.

## Files

| File | What it does |
|---|---|
| `src/main.tsx` | Starts React and renders `App`. |
| `src/App.tsx` | The page: header, controls, channel graph, AP table. Gets all live data from `useLiveUpdates`. |
| `src/useLiveUpdates.ts` | Opens the WebSocket `/ws/updates`, keeps the latest message (sent every 200 ms) and reconnects every 2 s if the backend goes away. |
| `src/api.ts` | One function per REST endpoint (`/api/interfaces`, `/api/capture/start`, `/api/channel`, …). Turns `{"error": "..."}` responses into an `Error`. |
| `src/types.ts` | TypeScript types for everything the backend sends, copied from `docs/API.md`. |
| `src/signal.ts` | Signal strength → colour: green ≥ -60 dBm, yellow -60 … -75, red < -75. |
| `src/mockData.ts` | Sample networks for `?mock`. |
| `src/components/ControlPanel.tsx` | Interface and mode, start/stop capture, replay a `.pcap` file, pin a channel. |
| `src/components/ChannelGraph.tsx` | The channel graph, drawn by hand in SVG: one hill per network over channels ch-2 … ch+2, as tall as its signal. |
| `src/components/AccessPointTable.tsx` | The network list: signal icon, SSID, BSSID, manufacturer, signal, channel, frequency, security. |
| `src/components/ui/` | shadcn/ui components (Button, Select, Badge, Card, Table), generated by the shadcn CLI. |
